    About Smart Study

    Smart Study is a web application designed to help students track real-time focus sessions without arbitrary timer cut-offs.

    Key Code Highlights:

    • Local Storage Isolation: Uses keys structured as `user_sessionName` so user data never leaks across accounts.
    • Open-Ended Timer: JavaScript `setInterval()` runs an incremental stopwatch algorithm instead of a countdown.
    • Archive Data Persistence: Completed tasks move to an array in LocalStorage containing total exact time taken.
